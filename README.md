# PoemDeck Corrections

[PoemDeck](https://sparkhub.bhwa233.com/poemdeck) 的诗词修正与内容补全仓库。

诗词正文来自开源语料库 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，共 32 万余首。语料是机器整理的，难免有错字、断句问题；而注释、译文、赏析上游完全没有，目前覆盖率不到 0.01%。

**这个仓库存的就是「人写的那部分」。** 同步程序每月从上游拉取更新，但凡这里出现过的字段，它一律不覆盖。

---

## 我想改一首诗，但不会用 GitHub

不需要会。直接在网站上改：

打开那首诗的页面 → 点「补译文 / 纠错」 → 填表 → 提交。

不需要账号，不需要懂 git。提交后系统会自动在这里开一个 PR，审核通过就生效。

## 我会用 GitHub

一首诗一个文件，文件名就是它的 slug（网址最后那一段）。

`https://sparkhub.bhwa233.com/zh/poemdeck/poems/cao-cao-xie-lu-xing`
→ `poems/cao-cao-xie-lu-xing.md`

文件不存在就新建，存在就直接编辑。

### 文件格式

```markdown
---
slug: cao-cao-xie-lu-xing
---

## 正文

- 惟汉廿二世，所任诚不良。
- 沐猴而冠带，知小而谋强。

## 注释

- 薤露: 乐府旧题，丧歌
- 廿二世: 二十二位皇帝

## 译文

汉朝传到第二十二代皇帝……

## 赏析

《薤露行》是曹操早期的一首重要的政治抒情诗……
```

**只写你要改的部分。** 没写的章节仍然沿用上游数据 —— 只补译文，就只写 `## 译文` 一节，别的不用管。

| 章节 | 内容 | 格式 |
| --- | --- | --- |
| `## 正文` | 诗词正文 | 每行一条 `- ` 列表项 |
| `## 拼音` | 正文拼音 | 每行一条，与正文行数一致 |
| `## 注释` | 字词解释 | `- 词: 解释` |
| `## 译文` | 白话翻译 | 自由段落 |
| `## 赏析` | 赏析文字 | 自由段落 |

### 几条约定

- **正文用简体。** 库里统一按简体存储，繁体页面由程序转换生成
- **改正文时行数不要变。** 断句本身有问题的，请开 issue 说明，不要在这里改结构
- **拼音会由机器人补。** 你改了正文但没改拼音，CI 会自动算好并提交到你的 PR 分支；如果你明确写了拼音，机器人不会覆盖
- **不接受**：广告、外链、与诗词无关的内容

## 修正多久生效

PR 合并后，同步程序会把改动写进数据库。网站有十分钟缓存，所以最长十来分钟。

## 这里没有的东西

- 诗词原始数据 —— 在 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)
- 网站代码 —— 在 SparkHub 主仓库
- 只有被人改过的诗才会在这里有文件，其余 32 万首都不在
